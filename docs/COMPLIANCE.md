# 合规基线（COMPLIANCE）

> 本文档记录本站在著作权、商标权与 EULA 合同义务三个层面的处理方式。
> **本站不提供法律结论**，只记录风险与缓解措施。所有条款引用以实测文本为准。

## 1. 三个层面必须分开

| 层面 | 性质 | 约束谁 | 对本项目的意义 |
|---|---|---|---|
| **EULA** | 合同（PARAWULIN 与安装/使用游戏的玩家之间） | 只约束**接受协议的玩家** | 违反可能构成违约；不直接约束未接受协议的访客；合同不能创设超出法定范围的著作权 |
| **著作权** | 法定权利 | 任何人 | 素材、剧情文本、UI 属受保护作品；复制/传播/演绎需授权或落入合理使用 |
| **商标权** | 法定权利 | 以商业性使用为重点 | 名称的**指示性使用**风险较低；**来源性使用**（品牌/Logo/域名/仓库名）风险较高 |

**非商业 ≠ 授权，也 ≠ 免责。** 非商业只降低与商业性使用相关的部分风险，不构成对 EULA 2.2(2)、2.2(4) 的豁免。

## 4. 名称使用（EULA 3.3 的准确描述）

3.3 是**合同条款**，其约束力来自双方合意，与商标法上的「指示性使用」是两套不同的评价体系：

- 指示性使用可降低**商标法**层面的混淆可能性评价，但**不改变 3.3 作为合同义务的存在**；
- 取得书面同意是**消除该项合同义务的直接方式**，但**不必然消除**著作权、商标法等其他层面的风险；
- 未取得书面同意而继续使用名称，构成**合同层面的风险敞口**，实际后果取决于权利人是否主张。

| 场景 | 用法 | 商标法风险 | EULA 3.3 风险 |
|---|---|---|---|
| 主品牌 | `影境手册 / PBZ Codex` | 无 | 无 |
| 副标题 | `《影之刃零》非官方中文攻略资料站` | 低 | 存在（合同层面） |
| `<title>` | `页面名 · 影境手册（《影之刃零》非官方攻略）` | 低 | 存在 |
| `<meta description>` | 含游戏名说明主题 | 低 | 存在 |
| OG 图 / Logo / Favicon | 原创几何图 | 无 | 无 |
| 域名 | 不含商标 | 无 | 无 |
| 仓库名 / Pages 路径 | `phantom-blade-zero-guide` | 中 | 中 |
| `keywords` 堆砌商标变体 | — | 中 | 中（禁止） |

## 6. 未决风险

- **EULA 2.2(4)（衍生作品）**：「事实陈述 + 原创表达」是**降低**被认定为衍生作品可能性的写法，**不是免责路径**。攻略的结构化组织（路线、顺序、分类体系）本身也可能被主张具有独创性。**该风险保持未决，需项目所有者书面确认接受。**
- **EULA 3.3（名称使用）**：未取得书面同意。副标题 / `<title>` / meta description / 正文名称四处是否保留，属待决事项（见计划 §H.2）。

## 7. 处理机制

- 联系入口：GitHub Issue 模板 `Takedown`（固定入口）。
- 承诺：**收到有效通知后先行下架争议内容，再行沟通**（先下架后核实）。
- **不承诺具体时限**（避免无法履行的 SLA）。
- `SITE_CONTACT_EMAIL` 未配置时，页面**不渲染任何联系方式**，只显示「联系方式待配置」，禁止编造邮箱或表单。

## 8. 禁止的表述

全站（含本文档、README、页面文案、meta）禁止出现：

- 「已获授权」「官方合作」「正版授权」
- 「符合法律」「经法律审核」
- 「非商业即合法」

只允许**风险等级 + 缓解措施**的描述方式。
